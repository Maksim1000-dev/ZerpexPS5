# ZerpexPS5

Хобби-проект: экспериментальный эмулятор PS5 для Windows (нативное исполнение
гостя на x86-64 + HLE системных вызовов + вывод графики через Vulkan).

> ⚠️ Статус: ранняя разработка. Реальные игры не запускаются.

## Что уже работает (честно)

- **Ядро**: загрузчик ELF64 (ET_EXEC/ET_DYN), аллокатор гостевой памяти
  (64K-выравнивание, identity-маппинг), анализатор образов.
- **Исполнение**: системные вызовы FreeBSD x64 (152 записи по psdevwiki),
  перехват syscall → UD2 + VEH, гостевые потоки, файловая система (/app0),
  динамические импорты (dynsym/rela.plt → страницы заглушек → HLE).
- **Первый пиксель (фаза 5.0)**: `sceVideoOut*`/`sceGnm*` → окно Win32 +
  Vulkan-свапчейн; гость рисует кадры в своей памяти, ядро показывает их.
  Vulkan грузится динамически (`vulkan-1.dll`), без линковки.
- **PM4-разведка (фаза 5.1)**: парсер type-3 командных буферов GCN
  (`src/emu/pm4.cpp`) — опкоды, регистры, вложенные INDIRECT_BUFFER.
- **Лаунчер** (`build/ZerpexLauncher.exe`): выбор ELF, приоритет видеокарты
  (`--gpu N`), аргументы ядра, настройки в `settings.json`.

## Что НЕ работает

- Рендеринг из PM4 в Vulkan (фаза 5.2 — следующий шаг).
- Retail-SELF, реальные игры, шейдеры гостя.
- Звук, контроллер.

## Сборка

1. Компилятор: [TDM-GCC 10.3.0](https://jmeubank.github.io/tdm-gcc/) —
   ожидается в `GCC/bin/` (не входит в репо).
2. Заголовки Vulkan (Khronos) — вручную в `vulkan/Include/` (не входят в репо).
3. ImGui 1.93.0 — вручную в `imgui-1.93.0/` (не входит в репо).
4. Сборка из корня:

```
GCC\bin\mingw32-make.exe -f Makefile build/ZerpexPS5.exe
GCC\bin\mingw32-make.exe -f Makefile build/ZerpexLauncher.exe
```

Запуск: `build\ZerpexPS5.exe test\hello3.elf` — тестовый гость рисует
чередующиеся кадры и выходит с кодом 5.

## Юридическая заметка

Проект не содержит и не будет содержать: ключей расшифровки, проприетарных
бинарников Sony, дампов игр. Только собственный код и HLE по открытым
документам (psdevwiki, GCN/mesa).
